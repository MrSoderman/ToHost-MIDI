MIDI 1.0

The complete MIDI standardMusical Instrument Digital Interface · 1983 · studio-wall reference
All bytes in hex · n = channel 0–F (ch 1–16)

Low level · the wire

31 250bit/s, ±1 % tolerance
8-N-11 start + 8 data + 1 stop = 10 bits
320 µsper byte (10 ÷ 31 250 s)
3 125bytes/s per cable

Asynchronous serial: no shared clock, every byte is framed by its own start and stop bit. Each cable is one-way, so IN and OUT run independently: one byte in and one byte out every 320 µs. Bit period 1/31 250 = 32 µs.

5 mA current loop on a 5-pin DIN (pins 4 and 5 carry the signal, pin 2 is the shield and is grounded at OUT only). Every IN is opto-isolated to avoid ground loops. THRU passes a copy of IN.

Anatomy of a message

1–3 bytes per message (SysEx: any length).

Status · 80–FF

bit 7 = 1 · type · channel
1tttnnnn

Data · 00–7F

bit 7 = 0 · value 0–127

LSB + MSB data bytes = 14 bits (0–16 383): Pitch Bend, Song Position.

Mode messages 7C–7F also act as All Notes Off.

Running status

Consecutive channel messages with the same status byte need the status sent only once. Real-time bytes don't cancel it; System Common and SysEx do. Note On with velocity 00 = Note Off, which keeps running status going.

REAL-TIME CUTS IN. F8–FF may be inserted anywhere in the stream, even in the middle of another message. Receivers must handle them without losing the message they are parsing.

Note numbers 0–127 · C-1 to G9

A0 = 21Middle C (C4) = 60A4 = 69 = 440 HzC8 = 108

Grand piano: 88 keys, notes 21–108. Yamaha names middle C “C3”; the note number is still 60.

MIDI Clock & PPQN

F8 is a steady pulse at 24 PPQN (pulses per quarter note). After 24 clocks every device knows a quarter note has passed. Devices run faster internal clocks (48, 96, 480…) and convert. It syncs tempo (arpeggiators, BPM-based delays) but carries no position, so use it with Song Position Pointer or timecode. It can drift, so studios often add word clock or ADAT sync.

GM · GS · XG · GM2

General MIDI 1 · 1991

MMA/JMSC baseline. 128 programs in 16 families; drums on channel 10 (keys 35–81); ≥ 24 voices; 16 channels. Must respond to CC 1, 7, 10, 11, 64, 121, 123, RPN 0–2, bend and channel pressure.

GS · Roland 1991

GM superset (SC-55). Variation tones via CC 0 / CC 32. Drum kits by Program Change on ch 10: Standard 1, Room 9, Power 17, Electronic 25, TR-808 26, Jazz 33, Brush 41, Orchestra 49, SFX 57. NRPN edits for filter, envelope and vibrato.

XG · Yamaha 1994

GM superset (MU80). Bank MSB: 0 normal (LSB = variation), 64 SFX voices, 126 SFX kits, 127 drum kits, so any channel can play drums. ≥ 32 voices; reverb, chorus and variation effects.

General MIDI 2 · 1999

Standardises GS/XG ideas. Bank MSB 79h = melodic, 78h = rhythm; LSB picks the variation. ≥ 32 voices, two drum channels (10, 11), more CCs and RPN 05, plus master tuning and effect SysEx.

File formats

.MID is the Standard MIDI File (SMF): type 0 = one track, 1 = parallel tracks, 2 = independent patterns. .KAR is SMF with karaoke lyrics. Both usually target GM, GS, XG or GM2 so they play anywhere. Professionals use DAW project formats instead, which also store setup, audio, effects and takes. Ways to ship custom sounds without rendering audio: DLS, SF2, RMID, XMF, XMI, SP-MIDI.

MIDI extensions

Sample Dump Standard (SDS)
Moves samples between devices as 120-byte SysEx packets with ACK/NAK/Wait handshaking (7E 01–03).
MIDI Time Code (MTC)
SMPTE time (hh:mm:ss:ff at 24, 25, 29.97 drop or 30 fps) carried as 8 F1 quarter frames per 2 frames, plus SysEx full frames for jumps. Wraps after 24 h. Give it its own port on a busy bus to avoid jitter.
MIDI Machine Control (MMC)
Transport for recorders and DAWs: play, stop, FF/rewind, pause, record, shuttle, locate/goto, cueing, record-ready. SysEx (7F … 06).
MIDI Show Control (MSC)
Real-time cues for lighting, sound, machinery and pyro in live and canned shows. Each cue in the controller's list maps to an MSC message; many devices now run it over Ethernet. SysEx (7F … 02).
MIDI Tuning Standard (MTS)
A tuning for each note: bulk dump request, bulk dump, and real-time single-note change. note xx yy: xx yy split a semitone into 16 384 steps (≈ 0.0061 cent).
MIDI Visual Control (MVC)
Lets MIDI drive video and visual presentation gear, using SysEx and ordinary channel messages.
3D Sound Control
RPNs for azimuth, elevation, distance and more, so synths can place sounds in 3D. All values 14-bit.
MIDI 2.0 · 2020
Universal MIDI Packet (32-bit words), 16 groups × 16 channels, 16-bit velocity, 32-bit controllers, per-note pitch and controllers, MIDI-CI negotiation and Property Exchange. Falls back to 1.0.
